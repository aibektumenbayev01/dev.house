# Счётчик слов

Программа анализирует текст из файла и показывает топ-10 слов, количество уникальных слов и длину самого длинного слова.

## Начало работы

Требуется Python 3.12+. Запустите из этой папки:

```bash
python word_counter.py sample.txt
```

На некоторых системах используйте `python3` вместо `python`. Пока шаблон выводит только сообщение о заготовке: реализуйте функции в `word_counter.py`. Файл `sample.txt` сохранён в UTF-8.

## Пример ожидаемого вывода

Для `sample.txt`, если не учитывать регистр и знаки препинания:

```text
Топ слов:
и: 16
помогает: 6
python: 5
код: 4
ошибки: 4
файл: 4
каждый: 3
мы: 3
понимать: 3
программа: 3
Уникальных слов: 123
Длина самого длинного слова: 16
```

В примере слова с одинаковой частотой упорядочены по алфавиту. Другой порядок допустим. Слово — последовательность букв; регистр и знаки препинания не учитываются.
