# Счётчик слов

Программа анализирует текст из файла и показывает топ-10 слов, количество уникальных слов и длину самого длинного слова.

## Запуск

Требуется Python 3.12+. Запустите из папки проекта:

```bash
python3 word_counter.py sample.txt
```

Вместо `sample.txt` можно указать путь к другому текстовому файлу в кодировке UTF-8.

## Обработка ошибок

- Если путь не указан, программа выводит «Укажите путь к файлу».
- Если указанный файл не существует, программа выводит «Файл не найден.».
- Если файл пустой или содержит только пробельные символы, программа выводит «Файл пустой.».
- Если файл содержит только числа, знаки препинания или другие символы без букв, программа выводит «Нету слов».

Во всех этих случаях программа завершается без traceback.

## Начало работы

Требуется Python 3.12+. Запустите из этой папки:

```bash
python word_counter.py sample.txt
```

На некоторых системах используйте `python3` вместо `python`. Пока шаблон выводит только сообщение о заготовке: реализуйте функции в `word_counter.py`. Файл `sample.txt` сохранён в UTF-8.
